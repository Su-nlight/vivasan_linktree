# Privacy Policy

*Last updated: 11 October 2026*

This Privacy Policy explains how information is handled on the personal portfolio and link tree website of **Sanjana** (online handle: Vivacious_San) accessible at `vivasan.netlify.app`.

---

## 1. Scope & Nature of Service

This website is a purely static personal portfolio and link hub. 
- It does **not** feature user account registration, login credentials, or comment forms.
- It does **not** process financial transactions or collect contact form submissions directly.
- It does **not** set tracking cookies, behavioral tracking pixels, or cross-site marketing analytics.

---

## 2. Personal Data Collected

### A. Data You Voluntarily Provide
Because there are no interactive submission forms on this site, we do not directly collect or store your personal identifiers (such as name, email address, or phone number) when you browse the site.

### B. Client-Side Preferences (Local Storage)
The website stores your preferred theme mode (`light` or `dark`) directly within your browser's `localStorage` under the key `vivasan-theme`. This data remains entirely on your local device and is never transmitted to any external server.

### C. Third-Party Services & Server Logs
When you visit the site, certain external assets are requested to render typography, icons, and interactive visual effects:
1. **Google Fonts** (`fonts.googleapis.com`, `fonts.gstatic.com`): Serves custom web fonts. Google may receive your IP address and browser headers as part of standard HTTP requests.
2. **esm.sh**: Delivers the React library module used for ambient background animation.
3. **Icons8** (`img.icons8.com`): Supplies social media icon imagery.
4. **Hosting Provider (e.g., Cloudflare Pages / Netlify / GitHub Pages)**: Standard web server logs may temporarily capture visitor IP addresses, browser user-agent, and access timestamps for diagnostic and network security purposes.
